# Task Manager

A command-line task manager with categories, priorities, due dates, and JSON file persistence, built with an OOP design (`Task`, `Category`, `TaskManager` classes) and a `rich`-powered CLI.

## Setup

1. Install dependencies:
   pip install rich pandas

## Run
python algorithm.py


## Features

- Add, delete, and view tasks
- Update task status, priority, and due date
- Mark tasks as completed
- Create and rename categories
- Assign/disconnect tasks to/from categories
- View tasks by category or view uncategorized tasks
- Auto-saves and auto-loads data from `tasks_data.json` on exit/start
